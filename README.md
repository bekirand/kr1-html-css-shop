## Краткое описание проекта

**SoundPulse** — многостраничный веб-сайт интернет-магазина премиального аудиооборудования (наушники с активным шумоподавлением, студийные мониторы ближнего поля, балансные ЦАП и усилители, портативная акустика).

Сайт разработан на чистом семантическом стеке **HTML5** и **CSS3** по методологии **БЭМ** в строгом соответствии с принципами чистого кода без оверинжиниринга (философия **Ponytail**). В проекте **не используются** тяжелые CSS-фреймворки (Bootstrap, Tailwind) и лишние сторонние библиотеки.

Проект спроектирован как основа для последующих контрольных работ:
- **КР №3:** адаптивная вёрстка под мобильные и планшетные устройства;
- **КР №4:** расширенная интерактивность на JavaScript (корзина, живой поиск, динамическая фильтрация);
- **КР №5:** миграция предметной области в SPA на React или Vue.

## Используемые технологии и подходы

1. **HTML5:** Семантическая разметка (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `address`, `details`, `summary`, `dialog`, `table`). Ровно один тег `<main>` на страницу.
2. **CSS3:**
   - Каскадные переменные (`:root`) для цветов, отступов, радиусов, теней;
   - Одномерное позиционирование через **Flexbox** (шапка, меню, карточки, группы кнопок);
   - Двухмерная раскладка через **CSS Grid** (каталог продукции, сложная двухколоночная структура страницы каталога со sticky-панелью);
   - Демонстрация всех типов позиционирования: `relative`, `absolute`, `sticky`, `fixed`, управление слоями через `z-index`;
   - Стилизация состояний интерактивных элементов: `:hover`, `:focus-visible`, `:disabled`.
3. **Методология БЭМ:** Полное именование классов по стандарту Блок-Элемент-Модификатор (`block__element--modifier`). Отсутствие презентационных и несемантических классов.
4. **Vanilla JavaScript:** Компактный нативный скрипт (менее 30 строк) для вызова `.showModal()` и `.close()` нативного диалогового окна.
5. **Доступность (a11y / WCAG AA):** Видимый контрастный фокус `:focus-visible`, связь `<label for="...">` и `<input id="...">`, семантические заголовки, скрытые ориентиры для скринридеров (`.visually-hidden`).

## Описание обязательных страниц

1. **`index.html` (Главная страница):**
   - Промо-блок (Hero) с описанием флагманской линейки и призывами к действию;
   - Блок ключевых преимуществ с иконками (титановые излучатели, гарантия 2 года, тест-драйв);
   - Секция популярных товаров с карточками в едином визуальном стиле;
   - Блок отзывов покупателей и звукорежиссеров;
   - Аккордеон часто задаваемых вопросов (FAQ) на нативных тегах `<details>` и `<summary>`;
   - Якорные переходы (`#advantages`, `#popular`, `#reviews`, `#faq`, `#contacts`).

2. **`catalog.html` (Каталог товаров):**
   - Навигационная цепочка хлебных крошек;
   - Двухколоночная раскладка на CSS Grid (`.catalog-layout`);
   - Фиксированная при скролле панель фильтров (`aside.catalog-filter` со свойством `position: sticky`);
   - Сетка карточек товаров на CSS Grid (`.catalog-grid`) с бейджами «Хит», «Новинка», «Скидка -18%».

3. **`product.html` (Карточка товара):**
   - Хлебные крошки с указанием пути к товару;
   - Медиа-галерея и детальное описание SoundPulse Pro Wireless;
   - Семантическая таблица сравнительных технических характеристик (`table`, `caption`, `thead`, `tbody`, `th`, `td`) с эффектом выделения строк `:hover`;
   - Блок сопутствующих аксессуаров и кнопки оформления заказа.

4. **`order.html` (Оформление заявки):**
   - Структурированная форма оформления покупки с логической группировкой полей через `<fieldset>` и `<legend>`;
   - Поля: Имя (`type="text"`), Почта (`type="email"`), Телефон (`type="tel"`), Модель (`<select>`), Цвет (`<select>`), Адрес доставки, Комментарий (`<textarea>`);
   - Чекбокс обязательного согласия на обработку персональных данных;
   - Все поля снабжены парными `<label>` со совпадающими `for` и `id`.

5. **`contacts.html` (Контакты и шоурум):**
   - Семантический блок `<address>` с адресом флагманского шоурума и ориентирами метро;
   - Карточки графика работы, телефонов, реквизитов компании;
   - Интерактивная форма записи на индивидуальное прослушивание в комнате звука.
